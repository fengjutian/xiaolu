# 性能跑分验收清单

## 自动化基线

- [ ] `cargo test --manifest-path src-tauri/Cargo.toml --lib`
- [ ] `npm run build`
- [ ] CPU、内存和磁盘取消标志测试通过
- [ ] 磁盘临时文件 Drop 清理测试通过
- [ ] 旧版历史记录反序列化测试通过
- [ ] 实时快照不包含进程清单，进程接口独立返回数据

## 跑分功能

- [ ] CPU 单核、多核、内存、磁盘、GPU 均可完成并显示结果
- [ ] 一个测试运行时，其余开始按钮禁用
- [ ] 取消后按钮恢复，可立即重新运行
- [ ] 128 MiB、1 GiB、4 GiB 磁盘测试均能清理临时文件
- [ ] 磁盘空间不足或临时目录无权限时显示明确错误
- [ ] WebGPU 可用时使用 D3D12；不可用时回退 WebGL2
- [ ] 五项完成后显示综合分，刷新页面后历史记录仍存在
- [ ] 旧 GPU Schema 显示兼容性提示

## 响应性与并发

- [ ] 跑分、驱动扫描和磁盘扫描期间窗口可拖动，侧边栏可切换
- [ ] 快速重复点击不会启动多个相同任务
- [ ] 概览轮询不会重叠；离开概览后停止
- [ ] 进程页独立刷新；离开页面后停止采集
- [ ] 取消、失败或切换 Tab 后没有永久 loading 状态

## 界面与环境

- [ ] 浅色、深色模式显示正常
- [ ] 125%、150%、200% Windows 缩放下无溢出
- [ ] 窄窗口下 Tabs 可滚动，测试卡片正确换行
- [ ] 键盘可访问 Tabs、容量选择器、开始和取消按钮
- [ ] 测试过程中休眠、切换电源模式或关闭应用后可正常恢复
