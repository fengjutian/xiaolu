# c_expand · C 盘瘦身与扩容（只读分析首版）

首版只做分区/未分配空间分析与扩容可行性预览，不做实际扩盘、不格式化、不移动分区。

## 运行方式

由 System Lens 工具箱宿主以固定参数启动：

```text
c_expand.exe --stdio
```

## 支持的动作

| 动作 | 说明 |
|---|---|
| `preview` | 只读分析并返回表格 |
| `apply` | 未实现，返回 `UNSUPPORTED_ACTION` |

## 分析内容

- 每个有盘符卷的容量、可用空间、文件系统、标签
- 磁盘号与分区样式（GPT/MBR），是否系统/引导卷
- 同一磁盘上紧邻右侧的未分配空间
- 可行性：可评估扩展 / 空间过小 / 不可直接扩展 / 需先转换 GPT / 信息不足

## 判定规则

| 状态 | 条件 |
|---|---|
| 不可直接扩展 | 右侧没有相邻未分配空间 |
| 空间过小 | 右侧未分配不足 1 GB |
| 需先转换 GPT | MBR 且可用+未分配超过 2 TB |
| 可评估扩展 | 右侧存在 ≥1 GB 未分配空间 |

## 边界

- 只读：不调整分区、不格式化、不移动数据、不下载分区软件
- Windows 磁盘管理只能向同磁盘紧邻右侧空间扩展；跨盘/左侧空间需第三方工具
- 实际扩容前必须备份、确认电源稳定并保留恢复介质；系统卷风险更高

## 构建与测试

```powershell
cargo build --release --manifest-path tools/c_expand/Cargo.toml
cargo test --manifest-path tools/c_expand/Cargo.toml
```

测试覆盖无相邻空间、空间过小、MBR 大卷与表格行构建。
